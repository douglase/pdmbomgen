pdmbomgen documentation
=======================

This site is the rendered documentation for
`pdmbomgen <https://github.com/douglase/pdmbomgen>`__,
the tool that converts SOLIDWORKS PDM Professional BOM exports into shareable Excel, HTML, and budget reports.
It is built from the Markdown files at the repository root,
which remain the canonical sources;
use the "Edit on GitHub" button on any page to change one.

.. toctree::
   :titlesonly:

   README <_docs/README>
   Budget guide <_docs/BUDGET_GUIDE>
   Pages setup <_docs/PAGES_SETUP>
   Budget plan <_docs/BUDGET_PLAN>
   Materials plan <_docs/MATERIALS_DB_PLAN>
   Design document <_docs/BOMGEN_DESIGN>

The vault and budget repository templates are not rendered here because they are meant to be copied out;
read them on GitHub:
`template-repo <https://github.com/douglase/pdmbomgen/tree/main/template-repo>`__ and
`template-budget-repo <https://github.com/douglase/pdmbomgen/tree/main/template-budget-repo>`__.
Refer to the `UASAL Development Guide <https://uasal.github.io/uasal_development_guide/>`__ for process questions not covered here.
